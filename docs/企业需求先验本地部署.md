# 企业需求先验本地部署说明

## 当前接入方式

Demo 不直接加载 Python、PyTorch、scikit-learn 或原始企业 CSV。训练阶段导出一个约 400KB 的聚合产物：

```text
runtime/enterprise-demand-prior.json
```

服务启动时读取该文件，按站点坐标找到最近的企业样本城市，再按油/电类型和预计到站小时读取需求倍率。该倍率只进入 FlowTwin 的到达强度和队列仿真，不改变高德路线、站点名称、价格或可行性判断。

## 私密文件边界

该文件由企业拟合数据推导而来，当前被 Git 忽略，不应上传公开 GitHub。公开代码没有它也能运行：

```text
文件存在且匹配成功 → enterprise-prior+simulation
文件缺失或站点无法匹配 → simulation
```

服务端 `/api/health` 只返回是否加载、模型版本、覆盖城市数和 WAPE 等摘要，不返回模型明细。

## 从训练目录重新导出

训练工程不属于本公开仓库。当前模型已经导出，训练虚拟环境已清理；Demo 运行不需要 Python、PyTorch 或 scikit-learn。若未来确实需要重新训练，请在私密训练目录中按 `requirements.txt` 重新创建隔离环境，再按实际数据路径重新导出：

```powershell
# 仅在需要重训时执行；不要在 Demo 目录安装训练依赖
python -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt
.\venv\Scripts\python.exe scripts\export_demo_prior.py `
  --archive '<企业拟合数据压缩包路径>' `
  --features data\features.npz `
  --metadata data\metadata.json `
  --candidate models\optimized-candidate-rolling-v2 `
  --output exports\enterprise-demand-prior.json
```

再把生成文件复制到 Demo 的私密运行目录：

```powershell
$demoRoot = '<FlowTwin-Demo 绝对路径>'
New-Item -ItemType Directory -Path (Join-Path $demoRoot 'runtime') -Force | Out-Null
Copy-Item 'exports\enterprise-demand-prior.json' `
  (Join-Path $demoRoot 'runtime\enterprise-demand-prior.json') -Force
```

不要复制 `orders.csv`、`device_logs.csv` 或整个 ZIP 到 Demo，也不要把它们放进部署包。

## 验证

启动 Demo 后检查：

```text
GET /api/health
```

应看到：

```text
dependencies.enterprisePrior.available = true
modelVersion = enterprise-hgb-20260811
```

规划时，评委模式的预测依据会显示企业先验的匹配城市、能源类型、需求倍率、匹配距离和模型置信度。这里的置信度描述的是离线先验与当前站点的匹配质量，不是实时站点准确率。
