# FlowTwin 架构与算法说明

本文档说明 FlowTwin 的数据分层、能耗与长途补能规划、到站时刻排队仿真、运营分流策略与模拟驾驶回放边界。

## 1. 数据分层

| 层级 | 来源与说明 | 处理方式 |
| --- | --- | --- |
| 地图、地理编码与路线 | 配置高德 Key 时来自高德 Web Service；未配置时使用内置全国主要城市/枢纽离线坐标库与走廊沙盒 | 服务端代理 + 文件缓存 + 离线走廊回退 |
| 实况天气 | 配置高德 Key 时来自高德实况天气接口 | 作为队列压力场景因子（`weatherFactor`），缓存过期明确标注 |
| 站点状态与排队预测 | 本地离散事件 / 聚合流量仿真生成（可选叠加私有离线需求先验） | 按预计到站时刻动态推演，区分排队耗时与补能服务时长 |
| 运营分流与 ROI | 后端确定性容量/分流模型计算 | 用于多目标对比与策略试算，仅作为场景估算参考 |
| 策略验证实验 | 30 个合成补能节点、1,000 次固定随机种子行程（默认 `20260719`） | 保证四类策略对比结果完全可复现 |
| 站内视觉（可选） | 本地 CPU PaddleOCR 服务（默认未启用） | 校验文件头与像素上限，图片纯内存解码，短视频处理完立即删除临时文件 |

## 3. 能量模型与多站规划

核心实现位于 `lib/energy.mjs` 与 `lib/longtrip.mjs`。

### 3.1 默认车辆参数

| 动力类型 | 能耗模型 | 参考满载续航 | 物理安全下限 |
| --- | ---: | ---: | ---: |
| 纯电（EV） | `0.18 kWh/km`，电池 `108 kWh` | 600 km | 2% |
| 燃油（Fuel） | `0.075 L/km`，油箱 `55 L` | ~733 km | 3% |
| 混动电分支 | `0.165 kWh/km`，电池 `20 kWh` | ~121 km | 2% |
| 混动油分支 | `0.056 L/km`，油箱 `60 L` | ~1,071 km | 3% |

- 满电且直达终点仍高于安全下限时，不强制插入补能站；
- 用户填写的「到达余量」与「最晚到达时间」为可选个人硬约束，留空时仍强制保留物理安全下限；
- 常规路线单次最多规划 6 站，极端长途触发 `adaptiveMaxStops` 时最多规划 12 站（候选上限 72 站，组合评估上限 12,000 次），预算耗尽会显式返回 `SEARCH_BUDGET_EXHAUSTED`。

## 4. 到站时刻排队与端口级仿真

核心实现位于 `lib/forecast.mjs`。

- **端口级离散事件仿真（`port-discrete-event`）**：当站点输入包含 `totalPorts`、`idlePorts`、`reservedPorts`、`chargingPorts`、`faultPorts`、`waitingVehicles` 与 `reservationQueueAhead` 时启用。严格区分已锁定枪位（`reservedPorts`）与待分配前置预约队列（`reservationQueueAhead`），按最早释放时间推演到站等待。
- **聚合流量仿真**：缺少端口明细时按站点容量、占用率、到达率、服务率与交通/天气因子估算排队等待。
- **P50 / P90 与停靠总账本**：
  - 排队分位采用同源口径：`p50 = wait * 0.82`、`p90 = wait * 1.65 + 3`（不含补能服务时长）；
  - 路线停靠总耗时 = `排队耗时 + 补能服务时长 + 支付驶离缓冲`（默认燃油 3 分钟、充电 5 分钟）；
  - 路线总 ETA = `驾驶时间 + 补能停靠总耗时`。
- **三目标比较与去重**：按「最快到达」「最稳妥」「最低成本」独立评分；若不同目标选出同一补能序列，自动合并为一张方案卡片并附加多个目标徽标。

## 5. 运营分流仿真与模拟驾驶

- **运营仿真（`lib/operator.mjs`）**：围绕平台优惠券金额、券窗口容量、价格、服务率与目标分群（全量/价格敏感/快充高频/通勤等），在合作可执行站点范围内计算分流率、拥堵站/承接站排队变化与场景 ROI；非合作站点仅可观测或作为引流来源，不会被选为执行目标。
- **模拟驾驶回放**：针对已通过可行性校验的方案，按道路折线投影站点并分阶段播放「行驶 → 预约 → 到站识别 → 排队 → 补能 → 收据 → 驶离」。场景素材位于 `assets/simulation/`（JPEG 格式），仅作视觉回放示意；到站 OCR 仅在用户主动触发且本地 CV 服务可用时执行。
