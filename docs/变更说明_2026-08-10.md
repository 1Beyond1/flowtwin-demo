# FlowTwin 本轮变更说明

## 视觉 MVP 收口

- 为视觉结果增加 `inferenceStatus`，区分合成演示、真实模型推理和未执行推理；
- 上传图片增加 PNG/JPEG/WebP 文件头校验，Node 与可选 Python 适配器采用同一边界；
- Python 适配器没有模型权重时明确返回 `not-run`，前端不再把适配器检查显示成“分析完成”；
- 增加 Python 标准库单元测试，覆盖服务合成模式、上传内容校验和支付不执行边界；
- 视觉页实测了内置合成画面和上传 fallback，均不会影响路线规划主流程。

## 材料与展示口径

- 链接页旧素材中的 `10`/`33` 项测试口径统一为当前 `127 / 127`；
- 重新生成风格比较页的桌面/移动端预览图，避免旧截图与当前页面不一致；
- 保留真实高德地图/POI/道路路线与演示仿真运营字段的边界说明；
- 不新增企业真实数据、真实摄像头、真实支付或强化学习的虚假表述。

## 本轮回归修复

- 修复目的地候选选择的文本替换边界：选择“南京南站”后不再把旧查询“南京”拼接成“南京南站南京”，并保留后面的路线约束。
- 修复评审模式 AI/规则对比面板把空的到达余量或绕行上限显示成 `0` 的问题；空值现在保持为“未指定”，与路线卡片和手动控件口径一致。
- 重新验证预测依据展开、视觉合成页、设置页版本检查和用户模式切换；本地 4197 端口主流程正常。

- 未部署 VPS、未推送 GitHub、未进行新的飞书远程写入；
